# ADR-0006: ยืนยันอีเมลด้วย OTP และตอบ register แบบเดียวกันทุกกรณี

- **สถานะ:** Accepted
- **วันที่:** 2026-10-14
- **เกี่ยวข้อง:** spec หัวข้อ 9–11

## บริบท
ผู้ใช้ต้องยืนยันอีเมลก่อน login ด้วยรหัสผ่าน และ AGENTS.md กำหนดให้ login/forgot-password ไม่เปิดเผยว่าอีเมลมีบัญชีหรือไม่

## ทางเลือกที่พิจารณา
1. ตอบ 409 เมื่อสมัครด้วยอีเมลซ้ำ: ใช้ง่ายแต่หน้าสมัครกลายเป็นเครื่องมือเช็กว่าใครมีบัญชี
2. ตอบ 202 เหมือนกันทุกกรณี และแจ้งเจ้าของอีเมลทางอีเมล

## การตัดสินใจ
ใช้ทางเลือก 2: อีเมลใหม่ได้ OTP ยืนยัน, อีเมลที่มีบัญชีได้อีเมลแจ้งว่ามีการสมัคร ทั้งสองกรณีตอบ 202 พร้อม challenge_id รูปแบบเดียวกันและ timing floor Login ที่รหัสถูกแต่ยังไม่ยืนยันได้ 403 `email_not_verified` Password reset สำเร็จนับเป็นการยืนยันอีเมล บัญชี Google ที่ email_verified=true ถือว่ายืนยันแล้ว

## ผลที่ตามมา
- ไม่เปิดเผยสถานะบัญชีผ่านหน้าสมัคร และเจ้าของอีเมลยึดบัญชีที่ถูกสมัครแทนคืนได้ด้วย reset
- ผู้ที่ลืมว่าเคยสมัครจะรู้ผ่านอีเมลแทนหน้าจอ
- ต้องมี SMTP/Mailpit ตั้งแต่ milestone 4 และจำกัดอัตราการส่งเพื่อกันการใช้ส่งอีเมลรบกวน
